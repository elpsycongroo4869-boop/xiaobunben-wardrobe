# 万卷书屋 · 怎么写 Point、怎么加书

万卷书屋有 **200 本精选书、800 个预设章节**。每本书的第 1 至 4 章各有一个 Point。第 0 章由制作人自由创作。选书时先看书名和章名，选定后才读取该章的完整 Point。

## 写一个能被拍下来的 Point

Point 是**一张静态照片最值得拍下的瞬间**。先把观众需要看见的事说清楚，再把服装、表情、灯光细节和取景交给摄制组。

- **世界和地点**。故事发生在什么地方，这个世界最特别的规则是什么？
- **这一秒发生了什么**。用一个完整动作，或动作刚结束后的状态，写清人物与道具之间的关系。
- **观众凭什么看懂**。用一个可见的物件、变化或空间关系解释关键事件。暗号、声音或过去发生的事，可以借留下的实物表现。
- **这一秒的感受**。点出人物为什么停下、迟疑或放松。留一点余味给表演和镜头。
- **和其他章节有什么差别**。检查四章是否换了关键事件，也尽量换一换场景、时间、光线和道具。比如同一本书可分别拍清晨工作、海边相遇、雾中归航与夜里的暗房。

例如《白瓷外壳的女机器人》第 4 章，把第一次看见海的影像落在可见物件上：红灯下，主角用夹子提起滴水的相纸，纸上已经显出白浪打在黑礁上的一圈泡沫。摄影师可以自己决定怎么同时拍清她的脸和相纸。 [查看完整书卡与四章原文](../src/wardrobe2-core/curated/bookshelf_extension/cards/B358.json)

## 可以直接发给 Chat 的扩充要求

> 帮我给万卷书屋新增一本《山火后的第一场雨》。先写这个世界的规则、选书时的一句简介，以及适合这个世界的服装或材质线索。再写第 1 至 4 章，每章给出章名和一个能拍成单张照片的 Point。每章写清地点、主角正在做的事、画面上能证明它的物件或变化，以及人物的情绪。让四章有不同的事件与画面。第 0 章保留自由创作。

只想试拍一个想法时，可以把写好的 Point 直接给 Chat，请它按该瞬间创作。如果要让这本书进入今后的随机候选，需要把书卡和索引一起装进自己的运行包。

## 把新书装进自己的候选书架

从 GitHub 下载或克隆源码，在自己的副本中操作。下面路径以仓库根目录为起点。

1. 在 [书卡目录](../src/wardrobe2-core/curated/bookshelf_extension/cards/) 参考现有 JSON。给新书一个未占用的 ID，格式如 `B901`，文件名用同一个 ID。填写 `id`、`title`、`world_logic`、`open_possibilities` 和可选的 `wardrobe_anchor`。在 `chapters` 里放四条 `{id, title, point}`，编号为 1 至 4。程序提供第 0 章，书卡无需再写一条。
2. 在 [世界索引](../src/wardrobe2-core/curated/world_index.json) 的 `books` 加入同 ID 的 `id`、`title`、`hook`。在 [书架目录](../src/wardrobe2-core/curated/bookshelf_extension/shelves/) 选一个现有书架，在 `entries` 加入同 ID 的 `id`、`title`、`intro` 与四个章节的 `id`、`title`。书架只放章名，完整 Point 留在书卡。
3. 同步 [catalog.json](../src/wardrobe2-core/curated/bookshelf_extension/catalog.json)。在对应 `groups` 条目里按书架文件的顺序更新 `ids` 和 `count`，更新总 `book_count`。按文件原始字节计算 SHA-256，更新书架的 `sha256`、新增书卡在 `card_sha256` 下的条目，以及世界索引的 `source_index_sha256`。已有书、章节和书架的 ID 请保留，账本用它们识别历史记录。
4. 在 [打包脚本](../scripts/build_release.py) 中更新对外清单的 `curated_world_count` 和 `preset_point_count`。执行 `python -B scripts/build_release.py` 重建运行 ZIP 和校验文件。保留自己的修改版与原下载包，上传修改版并重新绑定启动咒语。
5. 用隔离会话核对书名和四个章名能被选到，选中后读取正确的 Point，封签中也是同一段原文。候选和冷却会影响每轮能看见的书，所以新增书未在第一轮出现时可以再核对书架和账本。

只修改现有 Point 时，保留书与章节的 ID，更新该书卡的 `card_sha256` 后重新打包即可。改了书名或章名，也同步对应的索引或书架标题和摘要。旧作品继续使用其原封签。
