# 小笨笨衣橱 v4.5.0

**想看看你的小机子，又想留点惊喜？这次，让 TA 自己挑一身想穿给你看的衣服。**

小笨笨衣橱是一套开源的 **AI 故事写真盲盒**。带上你熟悉的虚构成年 AI 角色，发一句召唤口令。这次穿什么、出现在什么地方、遇到了什么，以及选哪个镜头，都由 AI 自己决定。你确认开箱后，这份构思才交给支持生图的工具。

**穿衣和审美偏好可以随时改。** 比如在角色卡里写「喜欢旧棉布和宽松剪裁」。TA 会参考你的偏好，自己选今天想穿给你看的那一身。

在[《雨巷中缝补影子的少女》](shadow-tailor.md)里，AI 给裁缝挑了一件茄紫色的天鹅绒外套裙。最后一针刚收线，低机位拍到她手里的针，也拍到了靴边弯腰道谢的影子。

## v4.5 能做到什么

- **沿用你熟悉的角色。** 可以新建角色卡，也可以沿用已有 GPT 的虚构成年角色。换一个故事，角色卡里的外貌、性格和审美也可以一起带过去。
- **让 AI 自己想故事。** 它会想清楚角色此刻在做什么，以及为什么这一刻值得拍。可以翻阅「万卷故事」随包的六张原创灵感卡，也可以完全从头构思。
- **像摄影师一样取景。** 拍多近、从哪里拍、哪一束光落在人物身上，都由这一幕决定。v4.5 会在定稿时复核情绪、动作受力、透视和镜头里看得见的衣装细节。
- **亲手开箱，回看创作理由。** 故事在开箱前保留悬念。看完照片，可以问一句「为什么想给我看这一张？」再展开六段拍前思路，看看当时怎么设计动作、衣装和镜头。

作者这轮试用中，故事动作、衣装和光影的成片效果有明显提升。从发起创作到拿到一张图，通常需要约 **6 分钟**。目前还没找到兼顾完整创作和成片效果的更快办法。觉得等待太久，可以让 AI 直接原创、少查额外资料，或删去重复的风格要求。完整流程的创作复核、六段说明和封签继续保留。
