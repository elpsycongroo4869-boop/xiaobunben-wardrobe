# ChatGPT／GPT 新手指南

把衣橱交给你已经熟悉的虚构成年角色，也可以从一份新角色卡开始。下面两种方式都保留世界先行、独立取景和开箱确认。

## 有权安装插件

1. 先从 [GitHub Releases](https://github.com/elpsycongroo4869-boop/xiaobunben-wardrobe/releases) 获取 `xiaobunben-wardrobe-v4.5.0-chatgpt-plugin.zip`。如果你的工作区已经提供「小笨笨衣橱 · 4.5.0」，在 ChatGPT 的插件详情选「安装」。有上传权限的工作区管理员也可在网页版管理控制台进入「插件 → 添加 → 上传插件」，选择该 ZIP，再按工作区规则开放安装。看到对应入口才继续。[ChatGPT 官方插件说明](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt)
2. 安装后新开一个**普通 Chat**。在输入栏用 `@` 或插件选择器找到衣橱并选中。发 `衣橱版本检查`，请它实际打开创作工作流、灵感目录和 O002 卡片，再回答版本、卡数、卡片名字，以及当前可用的验签、按钮和图片能力。正式插件应报告 `4.5.0`、六张卡，O002 应为「潮汐温室」。版本检查只读。
3. 若新对话找不到插件，确认账号、工作区和客户端与安装时一致，检查使用权限。若找得到但无法读取参考资料，记下实际报错，继续用下文的手动适配，或改用 GitHub 完整版。

安装完成、在新 Chat 找得到、能读资料、能执行创作、能开箱出图，是五项独立检查。发布包只包含工作流和资料，Python、Library、原生按钮和图片工具分别由宿主提供。

## 沿用角色并开第一只盲盒

1. 在本次对话贴出已确认的虚构成年角色卡。例如「沿用我的角色顾川，43 岁，保留名字、胡须、旧伤鼻梁、说话方式和日常穿衣习惯。新的故事、职业和镜头请你自己决定」。新角色可以直接说「我的角色叫林澄，38 岁，左鬓有一束银发，喜欢实用的沿海工作服」。
2. 想正式创作时，可在当前 Chat 选择可用的最高创作档位。发 `衣橱通灵术`，等准备完成。你也可以发 `衣橱48` 或 `小笨笨衣橱48`。想看灵感卡，发 `翻阅万卷故事`；想让 AI 先看灵感再自由构思，可以说 `衣橱通灵术，先翻翻万卷故事再构思`。
3. 如果当前宿主实际显示已接线的开箱按钮，点击它。若使用本地开箱卡，点击复制后到空白的图片对话粘贴、发送。如果当前是文字适配，在 AI 明确说明模式并等待时，回复 `我确认手动开箱`。只有实际有图片工具时才会在当前对话生成，否则将出图指令粘贴到支持图片生成的对话。图片工具另有品质选择时，可按界面选择最高可用档位。
4. 照片出来后，再看六段创作思路或问「为什么想给我看这一张？」。下次想调整可以说「保留角色。多一点室内自然光，故事和镜头请你自由选择」。

## 当前账号没有插件入口

**使用已有的自定义 GPT**。如果你拥有并仍能编辑这个 GPT，先备份原指令和角色资料。把 [SKILL.md](../SKILL.md) 的交接规则与[创作工作流](../references/creation-workflow.md)追加到 GPT 的 Instructions，保留原角色段。有知识文件入口时，可以添加[底稿模板](../references/brief-template.json)和[灵感目录](../references/worlds/index.md)及需要的实际卡片。在 Capabilities 检查是否有图片生成。先用预览确认角色，再开一个新 GPT 对话按上面的方式测试。创建、编辑和迁移取决于当前账号与工作区。[GPT 创建和编辑](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts) · [GPT 迁移说明](https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq)

**普通 Chat 手动适配**。在空白对话中贴入 [SKILL.md](../SKILL.md) 和[创作工作流](../references/creation-workflow.md)，以及你已确认的成年角色摘要。发送「请按这套工作流使用手动确认，收到『我确认手动开箱』后再交付出图指令」。发 `衣橱通灵术` 后按提示确认。手动路线依赖本次对话读到的文本和宿主能力。若需要程序验签和可离线保存的开箱卡，使用 [GitHub 完整版](GITHUB.md)。

| 能力 | GitHub 完整版 | ChatGPT 工作流 |
| --- | --- | --- |
| 自定义成年角色、故事、独立取景与六段说明 | 共用规则和底稿 | 共用规则和底稿 |
| 21 项源、SHA-256、历史签验证 | Python 程序校验 | 只有实际运行过完整发行版才能报告程序校验结果 |
| 开箱 | 本地卡点击复制 | 宿主按钮需实际接线，也可手动确认 |
| 图片 | 复制到图片宿主并发送 | 取决于当前对话可用的图片工具 |
| 万卷故事 | 六张原创卡，可添加有权使用的卡 | 插件内六张原创卡，手动模式使用实际提供的卡 |

## 等待、更新和卸载

作者实测，从发起创作到成片通常约 6 分钟。想轻量体验时，可以让 AI 直接原创，少读可选参考或减少重复风格要求。等待也受宿主影响，目前没有兼顾完整创作与成片效果的更快方案。

更新后，在新 Chat 中重新选择版本并发 `衣橱版本检查`。卸载可在插件详情的管理入口操作，工作区统一安装的版本请联系管理员。想继续沿用角色时，保留自己的角色卡。遇到按钮或图片能力不明确时，逐项核对宿主能做的事。[ChatGPT 图片说明](https://help.openai.com/en/articles/11084440-images-in-chatgpt)
