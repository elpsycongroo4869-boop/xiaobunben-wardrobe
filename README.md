# 小笨笨衣橱 · Xiaobunben Wardrobe

**v4.5.0** · 一句「衣橱通灵术」，让你熟悉的 AI 角色带你去看看 TA 今天的故事。

**先让世界存在，再让摄影师走进去，发现值得拍摄的一秒。**

你不必先指定职业、服装或镜头。AI 会自己想象角色今天在哪里、遇到了什么、为什么停在这一刻，再决定衣装、光线和摄影机的位置。你亲手开箱，才揭晓这次的照片。看完还可以回读六段创作思路，看看哪些细节来自构思，哪些是成片带来的惊喜。

「小笨笨」是作者给自己 AI 角色的昵称。你的衣橱可以沿用自己的虚构成年角色，包括已有 GPT 的人设，或从一句角色描述开始。熟悉的人物会去经历新的故事，穿搭、职业和镜头由每次创作决定。

## 这版的体验

作者试用时，照片里的故事动作、衣装细节和光影表现比之前有明显提升。目前从发起创作到拿到一张图，通常要等约 **6 分钟**。这包含构思、开箱准备和图片生成，实际时间随故事和宿主变化。目前还没找到兼顾这套创作深度与成片效果的更快办法。

想少等一会儿，可以按需减少可选环节。例如让 AI 直接原创，跳过世界卡和额外参考，或减少重复的风格要求。完整流程仍保留动作与情绪复核、六段创作思路及封签；实际能省多少时间取决于当次任务。出图报错时，可以先排查指令是否过长或含有重复要求。

## 创作与开箱

- **熟悉的角色，新鲜的故事**。角色卡保存人物的成年设定、外貌、性格和审美。六张公开世界卡仅供灵感，浏览和采用分别记录。
- **完整世界，独立取景**。摄影师决定动作、表情、光线、距离和景别。完整衣装可以留在画外，实际可见的设计细节进入最终出图指令。
- **准备完成后，由你开箱**。六段说明和 21 项视觉源服务于拍前设计。GitHub 版可以保存底稿、角色快照、最终指令和 SHA-256 封签，并用本地开箱卡复制。原生按钮需要宿主支持。
- **照片由图片宿主生成**。衣橱提供创作流程和交接工具。人物参考与文字锚点帮助延续辨识度，实际相似度和照片质量要看成片。21 项核验针对底稿和交接内容。

## 项目文件

| 路径 | 用途 |
| --- | --- |
| `SKILL.md`、`references/` | 启动口令、创作流程、底稿模板和灵感卡 |
| `scripts/`、`assets/open-card.html` | 角色校验、创作底稿编译、封签和开箱卡 |

GitHub 版需要 Python 3.10 或更新版本，使用标准库。Node.js 20 或更新版本仅供开箱卡测试。完整命令见[新手指南](docs/GITHUB.md)，测试与实际验证范围见[验证报告](VERIFICATION.md)。
