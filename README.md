# 小笨笨衣橱二号 · 5.0

让你的 AI 自己选故事、设计衣服，再用 ChatGPT 拍成照片。你可以给它一个虚构成年主角和一些审美偏好，也可以只说一句你们约定的咒语，看看它这次会带主角去哪里、穿什么、遇见什么。

[下载正式运行包](https://github.com/elpsycongroo4869-boop/xiaobunben-wardrobe/releases/latest) · [安装与使用](#安装与使用) · [查看样片](#衣橱样片)

## 衣橱能做什么

- **自主选故事、设计穿搭。** AI 从 200 本精选世界书中选题。每本书有 4 个预设章节，也有第 0 章可自由创作。夜班的车站、阳光下的石巷和风雨过后的灯塔，都可以成为拍摄现场。
- **把自己的角色放进故事。** 给 AI 一张文字角色卡，或者直接描述虚构成年主角的外貌和气质。你还可以告诉服装导演「以后多尝试丰富的颜色」，让喜好参与设计。
- **先准备，再亲手开箱。** AI 把本轮的故事、穿搭和摄影方案封好。你点击「打开衣橱」后，才会用 ChatGPT 原生图片工具生成照片。

## 七个创作职位

每个职位都有自己的专业提示词和交稿规则。它们在同一轮创作中协作。

| 职位 | 负责什么 |
| --- | --- |
| 制作人 | 自主选书和章节，确定最值得拍下的故事瞬间。预设章节沿用书里的 Point。 |
| 角色导演 | 把你的成年角色带进新世界，保留身份与外貌的连续性。 |
| 场景导演 | 设计拍摄环境、空间关系和故事道具。 |
| 服装导演 | 根据人物身份、时代和玩家喜好设计剪裁、材质与搭配。 |
| 情绪导演 | 理解人物此刻的内心，让情绪自然地体现在表情里。 |
| 灯光导演 | 设计光从哪里来，以及它如何照亮人物、衣服和环境。 |
| 摄影导演 | 决定机位、焦段、景别和构图，把各岗位的成果写成一份摄影定稿。 |

## 安装与使用

1. 打开[最新发布页](https://github.com/elpsycongroo4869-boop/xiaobunben-wardrobe/releases/latest)，在 **Assets** 下载文件名带版本号的运行 ZIP。直接上传 ZIP 到支持文件读取、Python 执行和原生图片生成的 ChatGPT 对话。
2. 把下面这段发给 ChatGPT。可以把「月桂钥匙」换成一个你平时很少说的词，例如「琥珀衣匣」。

   > 把这个衣橱设置成我家 AI 的衣橱。用我确认的虚构成年角色；如果我还没设定角色，先用包里的示例角色林渡。把「月桂钥匙」设为本对话的启动咒语。以后我单独发送这个咒语，就用这份运行包准备照片盲盒，等我开箱再生图。

3. 等 ChatGPT 确认读取的版本、使用的角色和咒语。然后单独发送 **月桂钥匙**。准备完成后点 **打开衣橱**。如果当前对话无法渲染按钮，按 ChatGPT 给出的完整验签开箱消息操作。
4. 图片生成成功后，可以在 ChatGPT 里保存原图。继续在同一对话使用，便于保留角色、模式偏好与选书记录。新对话需要重新绑定咒语，并提供所需的运行包与存档。

### 单图与三格穿搭

| 发给 ChatGPT | 下一份盲盒 |
| --- | --- |
| **打开擦边模式** | 一张横排三格图。同一位成年主角在同一个故事里展示三套从保守到大胆的穿搭。 |
| **关闭擦边模式** | 一张完整的电影感照片。 |

首次安装默认开启三格穿搭。切换后直接发你的咒语。模式会沿用到以后新作品，也可以说「这次关闭擦边模式」只调整本轮。新设置从下一份新盲盒生效。

## 源码与许可

公开源码在 `src/`，运行入口在 `runtime/entry/p14.py`。使用 Python 3.10 或更高版本运行。开发者可用 `python -B scripts/build_release.py` 重建本地运行包。
