# 小笨笨衣橱 · Xiaobunben Wardrobe

**想看看你的小机子，又不想指定穿搭/场景，想要点惊喜？这次，让 TA 自己挑一身想穿给你看的衣服。**

小笨笨衣橱是一套开源的 **AI 故事写真盲盒**。带上你熟悉的虚构成年 AI 角色，发一句召唤口令。这次穿什么、出现在什么地方、遇到了什么，以及选哪个镜头，都由 AI 自己决定。你确认开箱后，这份构思才交给支持生图的工具。

**穿衣和审美偏好可以随时改。** 比如在角色卡里写「喜欢旧棉布和宽松剪裁」。TA 会参考你的偏好，自己选今天想穿给你看的那一身。

在[《雨巷中缝补影子的少女》](docs/shadow-tailor.md)里，AI 给裁缝挑了一件茄紫色的天鹅绒外套裙。最后一针刚收线，低机位拍到她手里的针，也拍到了靴边弯腰道谢的影子。

## v4.5 能做到什么

- **沿用你熟悉的角色。** 可以新建角色卡，也可以沿用已有 GPT 的虚构成年角色。换一个故事，角色卡里的外貌、性格和审美也可以一起带过去。
- **让 AI 自己想故事。** 它会想清楚角色此刻在做什么，以及为什么这一刻值得拍。可以翻阅「万卷故事」随包的六张原创灵感卡，也可以完全从头构思。
- **像摄影师一样取景。** 拍多近、从哪里拍、哪一束光落在人物身上，都由这一幕决定。v4.5 会在定稿时复核情绪、动作受力、透视和镜头里看得见的衣装细节。
- **亲手开箱，回看创作理由。** 故事在开箱前保留悬念。看完照片，可以问一句「为什么想给我看这一张？」再展开六段拍前思路，看看当时怎么设计动作、衣装和镜头。

启用 ChatGPT 工作流后，先发 **`衣橱版本检查`**。确认读到 `4.5.0` 和六张原创卡后，可以单独发送默认口令 **`衣橱通灵术`**，也可以自己写一句，例如 **`星屿衣橱，今晚开门`**。选一句平时聊天很少说的文字，并提前告诉 AI 只有收到完整的一句才启动衣橱。这样更容易区分日常聊天、讨论口令和正式召唤。[设置自己的召唤口令](docs/CHATGPT.md#设置自己的召唤口令)

## 这版的体验

作者试用时，照片里的故事动作、衣装细节和光影表现比之前有明显提升。目前从发起创作到拿到一张图，通常要等约 **6 分钟**。这包含构思、开箱准备和图片生成，实际时间随故事和宿主变化。目前还没找到兼顾这套创作深度与成片效果的更快办法。

想少等一会儿，可以按需减少可选环节。例如让 AI 直接原创，跳过世界卡和额外参考，或减少重复的风格要求。完整流程仍保留动作与情绪复核、六段创作思路及封签；实际能省多少时间取决于当次任务。出图报错时，可以先排查指令是否过长或含有重复要求。

## 出图、开箱与保存

GitHub 完整版会核验 21 项视觉来源及 SHA-256 封签，保存角色快照、底稿和最终出图指令。打开本地开箱卡即可复制核验过的指令，再发给支持图片生成的工具。原生开箱按钮需要宿主支持，普通 Chat 也可以按指南手动确认。

角色文字设定与合法参考素材可以帮助延续人物辨识度，最终的相似度、表情与摄影表现要看实际成片。
