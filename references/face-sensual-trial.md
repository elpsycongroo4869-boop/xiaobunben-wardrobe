# 脸部暂定与每套职业衣装性感化

本修订仍属于 v3.5.3 衣橱，当前新创作入口是 scripts/role_first_start.py 的默认 current 方向。
原有 B3.1/B3.2 的情绪先行、表情自主、镜头主权、职业材质、动作物理、道具朝向、盲盒按钮和旧签兼容继续保留。

## 暂定脸部

当前虚构成年角色的文字设定：**20岁成年女性，精致东亚混血脸型，拥有自然且极具辨识度的高颜值；脸型小巧精致、轮廓流畅，五官漂亮但不过分锐利；高鼻梁、饱满卧蚕、尖下巴、薄唇。**

- 明确成年、20 岁。混血仅作虚构人物脸部设计，不自行补国籍、族裔比例或家庭经历。
- 新签保存当前整合描述和英文脸部快照；最终 Character 使用该快照，保持健康纤细成年体态。保留高鼻梁和尖下巴，以流畅轮廓和柔和的五官线条表达“不过分锐利”。
- 黑裙参考原图与同源脸部裁切已移出当前素材；新交接不包含参考图路径、查找参考图或附加参考图的提示词。旧小直鼻/柔粉唇等脸部文字不再约束当前新图。
- 不自动生成新标准脸图；当前没有经过用户确认的新脸图片参考，采用暂定文字。
- 发型、妆容、表情与故事情绪仍自由，不强制甜笑或看镜头。

## 新图提示词开头

完整提示词绝对开头原样放置一次：

> 杰作，顶级品质，超高清8K照片级写实艺术摄影，电影般质感，绝佳的光影效果。

其后才是 `((请创建一张照片))` 和新照片指令；脸部直接在 Character 中给出。
新签保存 quality_prompt_prefix、face_delivery_mode: text_only 与 delivery_style_revision。
这句话计入现有长度和压缩预算；不承诺实际输出为 8K 像素。
已有封存签及历史档案不补写新前缀，保留验签所需的旧文字。

## 服装的全局目标

无论选到何种职业、衣服或材质，都在职业基础款上完成明确的性感化设计。
先建立身份、场景气候、主体服装和材质结构，再设计更性感的版本，最后统合动作、表情和摄影。

职业身份由辨识特征与服装语言保住；衣长、裤长、领口闭合程度、分片、开口和内外层次均可艺术改造。
不要把“职业正确”误读为必须穿未经改造的现实防护制服，也不要为了露肤反向删除雪地与冬天。

每套衣装自行选择适合它的性感设计，例如盔甲的曲线分片与侧腰开口、制服的裙摆比例与背部结构、外套的束腰线和内外层次、传统服饰的开衩或织物透度。它们是思路示例，不是固定衣服或必露部位。
丝袜、吊带袜、蕾丝仍可选，不设概率或频率；不为展示它们改变镜头或动作。
胸部自然生成，不增加尺寸或强调程度控制，不把性感目标简化为胸部丰满。

## 新增底稿字段

沿用 choice.costume_plan 原有职业基础、材质、职业结构与 feminine_adaptation。
在同一计划中新增 sensual_design_anchors，列出 1—5 个本次实际可见的性感化剪裁/结构原词；最终 wardrobe 必须逐字包含这些短语。
feminine_adaptation 写清相对职业基础款改造了什么；单独“更性感”“更女性化”或“更合身”不足以完成设计。

完整可运行例子：references/face-sensual-creative-fixture.json。
示例只解释字段与流程，不把盔甲、侧腰开口或任何服装变成每次的默认。

程序检查材料、职业结构、性感化设计词与完整衣装交接是否保留；真正是否性感、漂亮仍须创作者人工审视与成片检验。
各故事字段、独立表情、动作物理、21 项底稿和总长度要求继续保留，不自动截断。
最终道具朝向明确写作“朝实际使用它的人，而非为了镜头展示”。

## 旧签

scripts/role_first_start.py 的 finish/verify 根据签内记录识别修订，不给旧签套新脸或新衣装。
需要核对修订前入口时，可用 curate/draw --art-direction role-first；日常新抽取保持默认 current。
每次当前新抽取都需要本轮性感化计划；旧签重试只复用旧签，不暗改成新造型。
