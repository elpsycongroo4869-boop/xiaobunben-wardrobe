# 小笨笨衣橱 2.3.1｜摄影语言随机引擎

## 为什么存在

小笨笨职业随机≠画面随机。必须让拍摄媒介、取景距离、光线、色调、颗粒、场面工作动作独立发生真实变化，但不能以摄影特效盖过职业。

## 四轴抽取

1. **摄影包（24类乱序袋）**：`references/camera-packs.json`。每24次成功默认出图，每种摄影包各一次。与16类世界乱序袋相互独立，不做审美加权。摄影包只在成功写入历史后占袋。
2. **镜头构图（14个）**：脚本 `SHOT_POOL`，等概率独立抽；画面距离随职业动作有限修订，仍需保留抽到的构图本质。
3. **故事瞬间（12个）**：脚本 `MOMENT_POOL`，等概率独立抽；若和职业任务矛盾，转化为有同样叙事作用的现场行为。
4. **风格强度**：轻度30%、中度50%、重度20%，先抽强度，后精调色调和粗糙度。强度改变风格显著度，不改变职业和世界。

镜头/瞬间/强度均采用 `secrets.SystemRandom` 的抽样；`--seed` 只能用于本地测试，不能声称真实随机。

## 原创世界兼容性

- 古代/奇幻世界里，现代拍摄媒介默认作为画面外的艺术语言，不凭空增加手机、摄像机、电视台。
- 重度 DV / CCD / 监控样式如果遮挡脸或职业线索，就降低噪点与遮挡幅度，但**保留该摄影包不可替换的核心视觉**；这属于保留母题的合理调整。
- 手机自拍包若遇上历史场景，应取“近距、广角、目光互动”构图，不创造手机、社交软件 UI。
- 夜景、雨景、运动、舞台等强场景特征不能无条件覆盖职业与世界设定；优先使用同类光感、对比、反射和拍摄行为替代。
- 不得重复地把不同职业引回卧室自拍。摄影包名字不是职业，摄影材料是成片表现方式而不是主人公的工作。

## 出图提示装配顺序（一定要落实到生成）

1. **视觉主语**：同一位成年东亚女性「小笨笨」，保持自然且可辨认的连续面容。
2. **世界和职业**：具体职业名、故事时刻、工作动作，世界背景的物理细节。
3. **职业证据**：至少两项可见证据（工作工具、职业衣物、工作环境、正在操作的对象）。
4. **摄影包**：引用 pack `name`、`medium`、`optics`、`lighting`、`palette`、`texture`、`framing` 中至少三个以上视觉差异点，实际以视觉约束生成。
5. **独立镜头与强度**：落实 `suggested_camera`、`camera_intensity`，但必须保留真实职业行为。
6. **排除退化**：写明不得用室内卧室/床上自拍/单纯美颜写真替换抽中职业，除非职业确实需要该地点；不得添加多余字样或水印（DV 时间戳或电视台台标也并非强制）。

## 防跑题验收

| 检查项 | 成功标准 |
|---|---|
| 职业 | 职业动作可识别、至少2处证据 |
| 世界 | 地点/时代与抽中类别相合，不偷换 |
| 摄影风格 | 至少3项视觉特征可辨，且不是上一张惯用视觉模板 |
| 人物 | 明确成年形象、整体连贯、面部可认 |
| 氛围 | 不以美颜和滤镜取代叙事 |
| 历史 | 仅成功照片登记摄影包，失败不占袋 |

如果一张图漂亮却只是卧室自拍，而抽中的是野外地理教师，应判失败，并修复提示优先级；不要把第二次相同错误当成功。

## 兼容旧历史

世界16类乱序袋识别 `version=2.0` 与 `2.1` 的成功随机条目，以防升级后世界袋重置；摄影包乱序袋只统计存在 `camera_pack_id` 的成功随机记录，不虚构旧照片摄影包。

## 诚实记录

图片生成本身不是脚本调用；脚本只能生成可验证抽签 JSON。必须实际读取抽签结果后再触发图片生成。摄影包不匹配时不能假称成功。历史文件必须写在持久化位置，ZIP 内历史并不跨会话自动同步。


## v2.2 拍摄编译门禁

默认出图前运行 `scripts/prepare_shoot.py`；具体规则见 `references/preflight-engine.md`。不能凭感觉把图像生成器输出当作正确随机结果。v2.2 `--commit` 必须带经过真实人工验收的审核文件；抽签与镜头轮换逻辑和 v2.1 一致。

## v2.3 独立交接提醒

以 `scripts/prepare_shoot.py` 输出 `generation_prompt` 为出图文本；若工具无法显式传入 prompt，必须承认交接不受控，见 `references/handoff-engine.md`。失败画面不计历史。

## v2.3.1 主体美感与职业同框

摄影包的抽签和镜头规则不变。在职业工作动作和两项证据成立时，额外检查人物是否因遮脸、过度宽松罩衫、杂乱景物或不良光线沦为配角。优先调整服装合身程度、人物与环境的视觉关系、真实工作表情与镜头调度，不换职业、摄影包或构图母题。详见 `references/aesthetic-engine.md`。

## v2.9.7 一人主角、多人世界：构图视觉层级

- 主角小笨笨始终是唯一明显视觉中心；职业现场不是强制独角戏。路人、同事、患者、游客、护送对象只在有叙事作用时出现。
- 对职业配角采用自然的层级安排：在已抽中的镜头景别与景深内，以站位、距离/体量、光比、表情细节和动作强弱把他们放到次要平面；工作证据与互动仍需真实可辨。
- 不额外抽取人数、不取消必要顾客或群体工作、不为弱化配角而破坏随机摄影包的核心视觉，也不为了让主角更大而强制改镜头或裁切。
- 成功验收增加 `visual_subject_hierarchy_match` 的人工判断；人数大于一不是自动失败，主角被配角抢镜才需要修正。
