# 衣橱 2.0｜抽签之后的世界观与职业创作引擎

**先读 `random-engine.md` 并获得真正抽中的类别、职业，再阅读本文。** 旧版「想三个候选后比较」不再使用，因为这会把模型的审美惯性伪装成随机。

1. **锁定结果**：大类、岗位与原创约束由抽签决定。不要因为飞艇/星图更好画或哥特风更讨喜，就替换职业。
2. **世界的1–2条规则**：现实职业遵守现实知识；历史职业保持文化与工艺合理性；奇幻/未来可发明物理或社会规则，但必须清晰可解释。
3. **为什么需要此职业？** 说明岗位具体承担的社会功能、工具、工作方法、时空与组织关系。
4. **此刻的任务**：选择一个能被镜头捕捉的动作、挑战或发现，而非普通站姿。
5. **地点和服装**：从职业需求决定区域、季节、天气、鞋靴、防护、衣料、层次；抽中的建议地点不适配时调整为更可信的地点。性吸引力不能凌驾于角色逻辑。
6. **摄影叙事**：保留随机指定的构图距离/镜头语言（除非工作安全性或具体动作不允许），让脸部识别、环境信息、真实动作同时成立。
7. **原创职业**：根据程序给定的行动、对象、特殊情境三个锚点创造新岗位：一个独特名称、一种不可替代的职责、一套独立工具、一套合理服装、一个眼前的任务。不要把地图师/占星师换个名字冒充原创。
8. **跨图去重**：职业、母题、服装轮廓、相机距离、动作、环境六维中争取至少四维与近期图片变化；最近3大类/10职业/6母题优先过滤。无法满足时优先换艺术细节，不轻易推翻随机职业。

所有场景均以同一名**虚构成年东亚女性角色「小笨笨」**为中心，视觉锚点见 `character.md`。照片真实自然；避免无端卡通、机械身体、同一张脸被换色制服或连续几张卧室眨眼镜头。

旧版 `theme-seeds.md` 只充当创意辅助，不能成为一个高频复用的小名单。
