# B3.2 · 服装材质主权｜实施规范

先定场景和职业，后定衣服

**设计顺序**：① 世界、天气和季节／真实温度 → ② 人物身份与职业 → ③ 职业所对应的核心服装结构及功能 → ④ 该服装的主导真实材质、工艺与配件 → ⑤ 在不替换职业服装骨架的前提下做大胆、妩媚、女性化的美术改造 → ⑥ 动作、摄影与景别整合（故事的情绪基调须先于具体动作和表情确定；封存前完成所有决定）。

- **职业服装的骨架必须保住。** 骑士的胸甲、护肩、甲裙及金属构件不能被“普通交叉裹胸＋亚麻裙裤”替代；飞行员的飞行服、工匠的防护/工具结构、传统服饰的织造和版型各有自己的设计语言。无制服的身份，也要从场景、工作内容和人物习惯出发选择服装，不硬造制服。
- **先定主材质。** 金属、皮革、漆面、天鹅绒、丝缎、织锦、羊毛、功能性纤维、牛仔、棉麻等都是自由选项，不设出现概率，不一概排斥亚麻。`scene_design.wardrobe` 明确至少一种主材质、职业轮廓、实际结构；摄影 `texture` 不得另行强塞服装未选择的材质。材质本身有真实的反光、折痕和接缝逻辑。
- **环境不向露肤让步。** 冬天雪地、暴风、冰原、寒冷山峰照样可以被自主创作选择，不能为了“露肤增强”偷偷换成暖季。寒地可以用完整冬装、金属盔甲、厚毛皮，也可以在幻想世界观和造型成立的情况下选择局部露腰、露背、露腿、镂空甲片或半透层次；**不要求每张都露肤**，不强制遵守现实军装的所有防护细节。优先让每件衣服真实属于它自己的世界。
- **女性魅力通过改造既有职业装，而不是替换职业装。** 腰腹、肩背、腿部、剪裁、金属结构、披风、束腰、镂空、薄透丝袜和蕾丝等都可能成为表达方式；服装保留职业辨识度，出不出丝袜仍由创作自由决定，不设骰子、频率或必穿义务。不要重复套用“无袖裹身上衣＋露腰＋开衩短裙裤”的单一模板，也不要为了避免它而强制轮换或设概率。
- **撤销新提示词中的数值驱动。** B3.2 不再主动附加 `Charm 85/100`、`+50% skin-and-line reveal` 或相似百分比句式；画面仍追求妩媚与女性整体线条，但改为从实际服装结构、材质和动作来达到目的。胸部依然自然生成，**不得加大、缩小或强调的正反向指令**。
- **现有优点不变。** 成年唯一标准脸、真实抓拍、镜头主权、情绪与表情自由、手部物理一致性、道具朝向、故事七字段＋独立表情、内部21项审查、相对基准压缩至少30%、哈希封存、单一真实「打开小笨笨衣橱」按钮以及点击后才生图；成功样片不自动登记。

## 实现与审查（新分支）

- 自主构思 `creative-brief.json` 中 `choice` 除已有世界、场景、角色、职业、情绪、摄影选择外，新增 `role_first_costume_design: true` 与 `costume_plan`；计划含 `climate_context`（气候环境）、`occupational_basis`（职业服装基本系统）、`structural_silhouette`（结构与轮廓）、`primary_materials`（1–5种主材质）、`feminine_adaptation`（怎样在该职业服装上做女性化改造）。顺序为**场景/气候→职业→服装结构→材质→女性化**，不能先决定裹胸再贴职业标签。
- 将最终衣装实际写在 `scene_design.wardrobe`，B3.2 上限从155扩至220英文字符，避免省略重要职业结构与材质。每一种 `primary_materials` 必须实际出现在 `wardrobe` 中；摄影纹理若凭空增加主流服装材质（例如没选亚麻却写了 `linen folds`）就拒绝封存。检查主要是文字审查，无法证明最终图片材质正确或动作无误，仍需眼睛验收。
- 旧随机只作可选创作工具；随机得出角色后仍要填写同样的 `costume_plan` 并完成设计，不允许随机分支跳过职业服装审查。旧的历史 pending 不重新封存。
- `scripts/fast_start.py curate → finish → verify` 完成后，先把当次 pending ZIP 保存进 `/小笨笨衣橱/pending/`，再显示唯一真实点击按钮；当前只是更新设计系统，不应自动出图。
