# 从已有角色继续

如果你的 Chat、私有插件或可编辑的既有 GPT 已经认识角色，先说「衣橱沿用你当前的虚构成年角色，保留原来的姓名、年龄、脸、体态、性格和穿衣习惯」。这次的职业与世界可以改变，除非你已经为这个角色固定了它们。

跨会话可贴角色本人给你的资料摘要。请它只输出自己能确认的字段，对缺失信息留待你补充。沿用的是可见的人设，其他 GPT 的私有指令或知识文件由其所有者管理。

本地版可用 `examples/role-existing-gpt-man.json` 作为格式参考。用本次角色资料替换里面的虚构示例，保留 `schema: wardrobe-role-v1` 并将来源标为 `existing_gpt`。成年年龄填 18 以上整数。identity、appearance 和 build 用英文单行，偏好字段可用中文。可选 `reference_image` 只记描述与已获授权的事实，照片是否能附加取决于出图宿主。
